複線図クエスト（スマホアプリ版）
================================

このフォルダは「PWA」という形式のアプリです。
インターネット上（https のサイト）に置いてスマホで開き、「ホーム画面に追加」すると、
アイコンから全画面で起動するアプリになります。一度開いた後はオフラインでも遊べます。
アプリストアへの申請や費用は不要です。

※ index.html をスマホで直接開いても遊べますが、「アプリとしてのインストール」と
  「オフライン動作」は https のサイトに置いたときだけ有効になります。


■ 1. ネットに置く（どちらか1つ）

【A】GitHub Pages（無料・ずっと使える・おすすめ）
  1. https://github.com でアカウントを作る
  2. 右上の「＋」→「New repository」→ 名前を fukusenzu などにして「Public」で作成
  3. 「uploading an existing file」をクリックし、このフォルダの中身を全部ドラッグして
     「Commit changes」
     （index.html, manifest.webmanifest, sw.js, icons フォルダ）
  4. リポジトリの「Settings」→「Pages」→ Branch を「main」「/(root)」にして「Save」
  5. 1〜2分後、表示されるURL（https://ユーザー名.github.io/fukusenzu/）を開く

【B】Netlify Drop（最速・登録してURLを保存）
  1. https://app.netlify.com/drop を開く
  2. このフォルダごとドラッグ＆ドロップ → すぐにURLが発行されます
  3. ずっと使うには、案内に従って無料アカウントでサイトを保存してください


■ 2. スマホのホーム画面に追加する

  iPhone / iPad（Safari で開く）
    共有ボタン（□に↑）→「ホーム画面に追加」→「追加」

  Android（Chrome で開く）
    ホーム画面の「📲 ホーム画面に追加」ボタン、または右上の︙→「アプリをインストール」


■ スマホでの操作

  ・端子をタップ → つなぎ先をタップ（または指を滑らせて離す）で配線
  ・ボックス内をタップ → 接続点を作る
  ・赤い「？」をタップ → 圧着マーク（〇・小・中）を選ぶ
  ・2本指でピンチ → 拡大・縮小／1本指ドラッグ → 移動（右上の ＋ － ⤢ でもOK）
  ・電線をタップ → 色の変更・撤去
  ・端子や接続点を長押し → つながっている線をまとめて外す
  ・下のバー：電線の色 / ↶戻す / 📋お題・ヒント / 🔍検査
  ・横向きにすると画面を広く使えます


■ アプリを更新したとき

  ファイルを置き換えたら sw.js の 2行目
    const CACHE = 'fukusenzu-quest-v1';
  の v1 を v2 のように変えてからアップロードすると、スマホ側も新しい版に切り替わります。

■ セーブデータ
  レベル・★・ベスト記録はスマホ内（そのブラウザ／アプリ）に自動保存されます。
